# Этап 7 — настольное приложение и Windows .exe

Собрано приложение «Срез» на PyQt6 + Qt WebEngine. Получен самостоятельный Srez.exe: Python отдельно не требуется.

**Статус: сборка и автономные проверки завершены. Пользователь подтвердил запуск настольного приложения в Windows.**

## Что сделано

- Отдельное окно с интерфейсом этапа 6: обзор, формы, сравнение и история.
- Встроенный FastAPI на свободном локальном порту; сервер запускается и завершается вместе с окном.
- Диалог настройки провайдера и ключа. Сохранение настроек не делает запрос к модели.
- Системный диалог сохранения JSON и открытие внешних ссылок в обычном браузере.
- Постоянная папка данных вне .exe; сохранение истории при замене сборки.
- Запуск с уже существующими данными через start-desktop.ps1 или Start-Srez.cmd.
- build.py и закреплённые зависимости для повторной сборки.

Интерфейс встроен в окно через Qt WebEngine, поэтому сайт и desktop используют один код. Сборщик включает три учебных ответа. Ваши ключи и runtime в .exe и архив исходников не включены.

## Что проверено

65 автоматических тестов прошли. Проверены настройки, сохранность существующего .env, завершение сервера, освобождение порта и история после перезапуска.

Готовый .exe запущен в режиме автономной диагностики: **17 проверок прошли**. Проверены встроенные HTML/CSS/JS, три учебных ответа, пять поставщиков, отсутствие изменений истории от учебного режима, запись и чтение файлов после перезапуска, библиотеки Qt и запуск Selenium Manager.

Упакованные модули desktop сверены с исходниками. Архив сборки проверен на приватный .env, пользовательскую историю и значение настроенного ключа в ресурсах и Python-коде. Контрольная сумма — в ../Srez-Windows/SHA256.txt.
