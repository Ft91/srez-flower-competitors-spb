## Уточнение по запуску Windows

Пользователь подтвердил: приложение запустилось, пустым было окно cmd.exe. Start-Srez.cmd изменён и завершает свою работу после запуска отдельного процесса. Исполняемый файл не менялся.

Сохранены 65 успешных тестов и 17 автономных проверок .exe. Автоматический тест встроенного окна из среды Codex остался с исходным результатом — код 49; подтверждение пользователя записано отдельно.

## Что входит в архив

Исходники, шаблон .env.example без ключей, документы, тесты, скриншоты и учебные ответы. .env, runtime, .git, build, виртуальное окружение и исполняемый файл исключены. Значения настроенных ключей проверяются в каждом включаемом файле.

Ограничение вложения в форме ДЗ — 100 МБ. Исходный архив укладывается в него. Сам .exe больше этого ограничения, поэтому подготовлен отдельно; для GitHub нужен отдельный Release либо сборка по инструкции.

В HOMEWORK.md указана ссылка на публичный репозиторий.
