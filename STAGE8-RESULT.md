## Локальные настройки

Файл .env содержит ключ провайдера и хранится только на компьютере владельца. В репозиторий включён .env.example без секретов. runtime, build, окружение Python и готовый исполняемый файл исключены.

## Windows

Пользователь подтвердил запуск приложения. Start-Srez.cmd завершает работу после запуска отдельного процесса. Самостоятельная Windows-сборка распространяется отдельно от исходников.
