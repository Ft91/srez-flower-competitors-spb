## Воспроизведение

После установки desktop/requirements.txt запустите `python -m pytest -q`. Самостоятельная проверка .exe: `Srez.exe --self-test путь-к-отчёту.json`. Она использует отдельную временную историю и не обращается к поставщикам или модели.

Файл examples/stage5/verification.json относится к ранним попыткам запуска Selenium в среде Codex. Для итогового статуса используйте examples/stage5/status.json: там отражён последующий успешный запуск из обычного PowerShell.
