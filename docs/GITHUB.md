# Публикация проекта

Публичный репозиторий проекта «Срез»: [Ft91/srez-flower-competitors-spb](https://github.com/Ft91/srez-flower-competitors-spb). Аккаунт владельца — Ft91.

## Состав публикации

В комплект включены только проверенные исходники, документация, пять скриншотов публичных сайтов и примеры результатов. .env, runtime, окружение Python, диагностические журналы и исполняемый файл исключены.

README и .gitignore подготовлены в проекте. Параметры создания репозитория описаны в [документации GitHub](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository).

Описание назначения приложения находится в CASE_STUDY.md.

## Windows-сборка

Srez.exe весит около 220 МиБ, поэтому не включён в Git и архив исходников. GitHub блокирует обычные файлы репозитория больше 100 МиБ; исполняемые сборки распространяют отдельно через Releases. [Ограничения GitHub](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).

Для проверки исходников достаточно инструкции сборки в README. Локальный готовый .exe находится рядом с проектом, в Srez-Windows.
